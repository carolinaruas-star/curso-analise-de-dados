Foi criado com o **propósito de registrar e organizar os conhecimentos desenvolvidos ao longo do curso**, reunindo estudos, práticas, scripts e projetos focados na manipulação, limpeza, exploração e visualização de dados.

## 📚 Sobre o curso

O curso **Análise de Dados com Python** aborda conceitos fundamentais e avançados para o tratamento, exploração e extração de conhecimento a partir de bases de dados reais.

Ao longo do curso, os conteúdos são explorados de forma prática, passando por etapas como:

- estrutura de dados e lógica em Python;
- importação e tratamento de bases de dados (limpeza, nulos e duplicatas);
- manipulação e agregação de dados com Pandas e NumPy;
- análise exploratória de dados (EDA);
- criação de relatórios estatísticos e geração de métricas;
- visualização de dados e interpretação de resultados.

### 🛍️ Mini-Projeto: Análise de Dados de Varejo

Projeto prático focado no **tratamento, limpeza e análise exploratória de dados do setor varejista**.

O projeto utiliza Python, Pandas e Jupyter Notebook para processar a base de dados bruta, realizar a limpeza dos dados (gerando um dataset tratado) e extrair métricas sobre as vendas do varejo.

O projeto reúne as seguintes etapas e arquivos:

- 📊 Tratamento da base de dados bruta (`Base Varejo.csv` → `df_limpo.csv`);
- 📓 Notebook com as análises detalhadas (`Miniprojeto_Analise_Dados_Varejo.ipynb`);
- 📄 Documentação individual do projeto (`README_AnaCarolinaPereiraRuas_T9.md`).

📁 [`mini-projeto/`](./mini-projeto)
